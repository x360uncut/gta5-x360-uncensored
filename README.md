# GTA V Xbox 360 - Uncensored Russian Subtitles Mod & Toolkit

> Первый полноценный перевод GTA V без цензуры для консоли **Xbox 360 (RGH / Freeboot / эмулятор Xenia)** с инструментами декомпиляции и автопатчинга.

---

## О проекте

Официальная русская локализация GTA V от компании «1С» на релизе подверглась жесткой цензуре: оригинальные ругательства сценаристов Rockstar (*fuck, motherfucker, shit, cunt, asshole, cocksucker*) были заменены на сопливые «черт», «хрен», «блин», «ублюдок» и «гребаный».

Если на ПК спустя годы появлялись разрозненные попытки частичного перевода через OpenIV, то на **Xbox 360** за 11 лет существования игры нормального матерного перевода не появилось вовсе из-за сложности формата:
- Вложенные Big-Endian архивы **RPF7** внутри `xbox360a.rpf` (`data/lang/russian.rpf`).
- Шифрование таблицы оглавления (TOC) ключом **AES-256-ECB**.
- Проприетарное сжатие данных **Microsoft Xbox 360 LZX / XCompress**.
- Бинарный формат таблиц локализации **GXT2** с хешами RAGE Jenkins One-At-A-Time (joaat) в Big-Endian кодировке.

Этот проект предоставляет готовый **автопатчер в 1 клик**, базу из **1 889 отредактированных реплик в 221 файле** и открытый инструментарий для моддинга консольной версии GTA V.

## Быстрый старт (Установка)

### Вариант 1. Автоматический патч вашего файла `xbox360a.rpf`

1. Склонируйте репозиторий:
```bash
git clone https://github.com/x360uncut/gta5-x360-uncensored.git
cd gta5-x360-uncensored
```

2. Скачайте скомпилированный языковой архив `russian_uncensored.rpf.gz` (из раздела **GitHub Releases** или нашего Telegram) и положите его в папку `data/`:
```bash
# Либо укажите путь к нему через флаг --payload:
python3 patcher.py /path/to/xbox360a.rpf --payload /path/to/russian_uncensored.rpf.gz
```

3. Запустите патчер, указав путь к вашему файлу `xbox360a.rpf`:
```bash
python3 patcher.py /path/to/xbox360a.rpf
```

Патчер автоматически:
- Проверит сигнатуры RPF7 и валидность контейнера.
- Сделает безопасный атомарный бэкап оригинальной локализации (всего 7.6 МБ, а не 2 ГБ всего образа).
- Вживит архив с матами прямо внутрь `xbox360a.rpf` по точному секторному смещению `0x26491200`.

3. Залейте готовый `xbox360a.rpf` на жесткий диск Xbox 360 в папку с игрой:
```bash
# Через наш FTP-скрипт (укажите IP вашей консоли):
python3 upload_ftp.py --ip 192.168.1.XXX --file /path/to/xbox360a.rpf
```
Или вручную скопируйте через Aurora / DashLaunch FTP в `Hdd1:\Games\GTA5\xbox360a.rpf`.

## Встроенные инструменты

### `gxt2_tool.py` - Консольный редактор GXT2 (Xbox 360 & PC)

Автономная Python-утилита для декодирования, кодирования и инспекции таблиц локализации GTA V:
```bash
# Декодировать один .gxt2 в читаемый JSON:
python3 gxt2_tool.py decode trev1.gxt2 trev1.json

# Собрать JSON обратно в Big-Endian GXT2 для Xbox 360:
python3 gxt2_tool.py encode trev1.json trev1_mod.gxt2 --platform x360

# Собрать ВСЮ базу uncensored_subtitles.json (221 файл) в папку с GXT2 файлами:
python3 gxt2_tool.py encode data/uncensored_subtitles.json --output-dir out_gxt2/ --platform x360

# Декодировать целую папку с .gxt2 файлами в один сводный JSON:
python3 gxt2_tool.py decode out_gxt2/ combined_subtitles.json

# Посчитать хеш метки (RAGE Jenkins joaat с побайтовым ASCII-lowercasing):
python3 gxt2_tool.py hash SUB_PHILIPS_01
```

## Архитектура и реверс-инжиниринг

1. **Размещение в образе**:
   В Xbox 360 версии GTA V основные сюжетные тексты находятся не в `common.rpf`, а во вложенном архиве `xbox360a.rpf/data/lang/russian.rpf`.
2. **Смещение и секторный лэйаут**:
   Внутри `xbox360a.rpf` архив `russian.rpf` лежит без шифрования и без компрессии на смещении `0x26491200` (размер сектора: 512 байт, выделенный лимит: 7 647 232 байт / 14 936 секторов).
3. **In-Place Patching и защита от повреждения**:
   Наш пересобранный `russian.rpf` со сжатием XMem занимает около 3.75 МБ. Мы выравниваем его нулевыми байтами до исходного размера 7 647 232 байт, что позволяет осуществлять бинарную замену в `xbox360a.rpf` мгновенно без пересборки всего 2.1 ГБ образа игры.
   - Патчер **не пишет байты вслепую**: перед записью проверяется сигнатура `RPF7` на оффсете 0 и целевом оффсете `0x26491200`, а также валидируется размер сектора.
   - Если образ уже был ранее модифицирован сторонними утилитами со сдвигом секторов, патчер безопасно завершит работу с ошибкой, не тронув файл.
   - Перед любой записью автоматически создается атомарный бэкап оригинального блока (`.backup_russian_rpf`, 7.6 МБ).
4. **Совместимость и ограничения**:
   - Поддерживаются консоли с **RGH / JTAG / Freeboot** и ПК-эмулятор **Xenia**.
   - На непрошитых (Retail / LT+ 3.0) консолях запуск модифицированных RPF технически невозможен из-за аппаратной проверки криптографических подписей Microsoft XEX/XGD3.
   - Текущая версия патчера протестирована на чистом оригинальном дампе Play Disc (диск 2 / `xbox360a.rpf`).
   - Сюжетные миссии (Тревор, Франклин, Майкл) берутся строго из `xbox360a.rpf`, так как в Title Updates Rockstar обновляла только мультиплеерные компоненты.
